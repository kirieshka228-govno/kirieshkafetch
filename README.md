# kirieshkafetch
Пародия на fastfetch но без кастомизации

Открывается почти что моментально и отображает важную информацию о системе

Запуск: Открой командную строку, перейди в директорию в которой находится файл, напиши `kirieshkafetch` или `kirieshkafetch.exe` (Также можно добавить программу в PATH чтобы из любого места открыть её)

### Требования:

* **ОС:** Windows 10/11 (Windows 7 не поддерживается)

* **Процессор:** Любой

* **[.NET 10](https://dotnet.microsoft.com/ru-ru/download/dotnet/10.0)**
